# 飞书问卷改题说明｜AI Radar 整站反馈

给飞书 AI / 表单编辑器用。按本文**整份替换或改到一致**后发布，把**填写链接**发回即可。

---

## 一、问卷定位（必读）

| 项 | 内容 |
|----|------|
| 问卷名称 | `AI Radar 反馈与建议` |
| 用途 | 收集对**整个站点/栏目**的意见，不是单条卡片打分 |
| 谁填 | 读过 AI Radar 的读者 |
| 不要做什么 | 不要「卡片 ID」题；不要依赖 URL 参数预填；不要必填渠道码 |
| 单卡赞踩 | **不在本问卷**；由网站卡片按钮另做 |

一句话简介（可放问卷说明区）：

> 欢迎反馈 AI Radar 的内容与体验。本问卷针对整个栏目，无需填写卡片编号。单条信号是否有用，请直接在网站对应卡片上操作。

---

## 二、相对旧版：删除 / 保留 / 新增

### 删除（必须去掉）

1. **卡片 ID**（必填/选填均删）——站点无法用 URL 预填，手填体验差  
2. 任何「请保持链接带入的内容，勿改」类说明  
3. 针对**单条推送**的有用/没用评分（若有）——改由网站按钮完成  
4. 依赖 `?card_id=` / `?ref=` 预填的说明文案  

### 保留并改写

- 「漏报」类开放题 → 保留，改为整站语境（见下题）  
- 「补充建议」类开放题 → 保留  

### 新增

- 可选单选：**你从哪里知道 AI Radar**（弥补无法预填渠道）  
- 可选：**联系方式**（愿意被回访时再填）  

---

## 三、题目清单（按此顺序；名称与选项请尽量一字不差）

### 问卷说明（非题目）

使用上文「一句话简介」。

---

### 第 1 题｜整体评价（单选 · 必填）

**题干：** 整体而言，AI Radar 对你有帮助吗？

**选项：**

- 很有帮助  
- 有一些帮助  
- 一般  
- 没什么帮助  
- 说不清 / 刚接触  

---

### 第 2 题｜最有价值的部分（多选 · 选填）

**题干：** 你觉得哪些部分最有价值？（可多选）

**选项：**

- 市场信号 / 事件卡片  
- 判断与「所以呢」(so what)  
- 工具雷达 / 实操向信息  
- 信源质量与一手感  
- 更新频率 / 班次节奏  
- 页面好读、好扫  
- 其他（请在后面开放题说明）  

---

### 第 3 题｜主要问题（多选 · 选填）

**题干：** 目前最影响你使用的问题是？（可多选）

**选项：**

- 信号太多，筛不动  
- 和我无关的内容偏多  
- 判断偏浅或证据不足  
- 更新不够及时  
- 有事实错误或过时信息  
- 页面难用 / 找不到重点  
- 不知道怎么订阅后续更新  
- 暂时没明显问题  

---

### 第 4 题｜漏报（开放 · 选填）

**题干：** 有没有你觉得重要、但 AI Radar 漏掉或覆盖太晚的方向 / 事件 / 信源？请尽量写具体名称或链接。

**填写提示：** 可写「谁发的、什么事、为什么重要」。没有可留空。

---

### 第 5 题｜有误或需更正（开放 · 选填）

**题干：** 若发现内容有误、过时或误导，请写下来（标题关键词、大致日期或链接均可）。

**填写提示：** 这类反馈我们会优先处理。没有可留空。

---

### 第 6 题｜其他建议（开放 · 选填）

**题干：** 还有什么想说的？（体验、栏目方向、你希望多看到什么等）

---

### 第 7 题｜你从哪里知道我们（单选 · 选填）

**题干：** 你从哪里知道 AI Radar？（选填）

**选项：**

- 公众号  
- 朋友或同事推荐  
- 飞书群 / 社群  
- 搜索引擎  
- GitHub / 技术社区  
- X (Twitter) 或其他社媒  
- 其他  

---

### 第 8 题｜联系方式（开放 · 选填）

**题干：** 若希望我们就你的反馈再联系你，可留下微信或邮箱（选填，仅用于回访，不作营销）。

**填写提示：** 不留也可正常提交。

---

## 四、设置与发布要求

1. **提交后提示：**「感谢反馈。单条卡片请在网站上点「有用 / 没用 / 有误」，本问卷无需卡片编号。」  
2. **不要**开启「仅限组织内」——外部读者要能填（若飞书权限允许「互联网公开填写」，请打开）。  
3. **不要**做卡片 ID 隐藏题或预填题。  
4. 发布后请提供：  
   - **填写链接**（可公开打开的那种）  
   - 若有：**管理/结果查看**说明给你自己留存即可，不必发给站点
