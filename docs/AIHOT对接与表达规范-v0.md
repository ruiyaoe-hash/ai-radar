## 决策核（保持不变）

这些规则仍以 [`CARD_SPEC.md`](../CARD_SPEC.md) 和 [`docs/DECISION-SIGNAL-FULL-SPEC.md`](./DECISION-SIGNAL-FULL-SPEC.md) 为准。人读层换说法，不放宽门槛。

- **P0**：今天没看到会做错或错过决策。
- 传闻（`rumor`）最高是待证，不能当成今日必看。
- 正式进入今日必看，需要一手或官方确认（`confirmed`）。
- 只有媒体二手（`role=report`，没有一手或官方链接）不能升成正式 P0。机器门闩仍在 `scripts/annotate_gates.py`：`media_alone` 只在有晋升意图时写下。
- 写了 `so_what` 就必须有非空 `falsifier`。写不出证伪，就不要写判断。
- 跳过纪律保留：敢不跟。跳过原因仍要说得清，只是不铺进主报正文。

## 两层

| 层 | 放哪里 | 可以有什么 |
|----|--------|------------|
| 机器层 | 归档 JSON、看板字段、RSS guid | `evt-` / `cand-`、`status`、`priority`、`sources`、班次、入库时间、ingest 统计 |
| 人读层 | 飞书或私有池里的主报；卡片的 `title`、`objective`、`so_what` 里给人看的句子 | 完整口语。不贴卡号，不贴候选池编号，不贴抓取统计。私人选型不进公开仓正文 |

`id`、`candidate_id`、枚举、来源角色留在 JSON。人读句子里不要出现它们。

## 人读层十条

1. 私聊和主报是人读层。JSON 卡是机器层。人读层不写 `evt-`、`cand-`，也不写 ingest 条数或退出码。
2. 每条按这个顺序：标题 → 一句话是什么（40 字上下）→ 关键数字 2 到 4 个 → 所以呢 → 若证伪 → 链接。
3. 一句一事实。不要用分号把时间窗、决策和另一条新闻串进同一句。
4. 英文专名第一次写成「英文（中文）」。同一张卡里再出现，只写英文或只写中文，不再括注。MoE、API 这类常识词可以不括，或全文只在第一次括一次。
5. 「所以呢」单独成行，对应 `so_what.impact` 和要做的动作。不要塞进事实句。
6. 跳过清单默认不进正文。需要审计时，用折叠段「本班先不跟（N）」，最多 5 条，其余不展开。
7. 声音像口头跟同事讲。正文说「今日必看 / 可关注 / 先不跟」。不说「升格 / 不入板 / 正式 P0」。这些词留在卡的机器字段。
8. 用自己的主谓宾重说。许可证全称、平台全家桶、推理栈清单不要堆在第一屏，放到 `access` / `integration` 或展开字段。
9. 数字用阿拉伯数字。价格写成「约 16 元」这种能直接听懂的说法。
10. 事实必须对得上原文。写不出证伪就不要写「所以呢」。传闻就标明传闻。

禁止的压缩例子：「权重能下」。写成「模型权重可以下载到自己的电脑或服务器上使用」。

## 主报骨架

```markdown
**今日必看 · 标题**

**是什么：** 一句完整的话。

**要点：**
- 一个数字或一个事实。
- 再一个事实。

**所以呢：** 这周具体做什么。

**若证伪：** 如果……，就收回这句判断。

原文：https://…
```

`可关注` 用同一骨架。还有效的旧条目也可以用，但不要和本班新条写进同一句。

## 样例（Muse Spark Open）

机器层仍保留完整 `objective`、`sources`、编号和工具字段。下面只是人读层。

**今日必看 · Meta 放出 Muse Spark Open**

**是什么：** Meta 放出一份大模型。模型权重可以下载到自己的电脑或服务器上使用。

**要点：** 总参数 816B，每个词大约激活 42B，上下文最长 1M token。它能读文字、图片、音频和视频，主打长程写代码和智能体任务。权重可以在 Hugging Face 下载，也可以走托管接口。许可可以免费用，大厂商卖接口要另议。它和上周的 Muse Wonder 不是一条线，Wonder 是闭源接口。Apple 演示过两台 Mac Studio 在本地跑，门槛高，别默认家里的电脑能跑。

**所以呢：** 如果你走开源或自己托管，或者怕闭源配额用完，这周用同一套长程写代码的题，把 Spark Open 的托管接口和你现在用的模型对打一遍。

**若证伪：** 如果独立评测显示，它在真实的长程写代码和智能体任务上稳定弱于同样成本的方案，或者托管价格用不起来，就收回「必须放进对照表」。

原文：https://research.meta.ai/blog/muse-spark-open

当日私人主报不进公开仓，只在飞书或私有池。`DIGEST_LATEST.md` 只保留占位，不要往里写称呼或选型。

## 对接（只读，不做镜像）

Alba 要对照外界精选时，默认读 Agent Markdown API，不必装 Skill，也不必先接 MCP。四种读法是同一份数据。

| 顺序 | 方式 | 什么时候用 |
|------|------|------------|
| 1 | `https://aihot.news/api/v1/agent/latest`（以及 hot / search / daily） | 问讯、补盲、对照日周报 |
| 2 | JSON `/api/v1/items` 等 | 只有要进候选池、做字段级 diff 时 |
| 3–5 | MCP、Skill、RSS | 不比第 1 种更多字段。RSS 缺推荐理由，不够做彻底对照 |

组织内部阅读可以。不要对外转售或白标。本仓不镜像 AIHOT 正文，不改池入库，也不改飞书 webhook。

旧域名和旧的 `/api/public/*` 在 2026-10-31 停用。地址用 `aihot.news` 加 `/api/v1`。
